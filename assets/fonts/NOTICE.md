# Icon font notice

`HerdrAgentIconsAlkaid-Regular.otf` is what this plugin installs: the Max
face below with nine glyphs added at U+E1B7–E1BF (Claude Code, Codex and
Cursor harness marks; Claude, z.ai, DeepSeek, OpenAI and Gemini model marks,
all from @lobehub/icons 5.0.1 under the MIT license; and a one-cell version of
the Dubhe logo). It is renamed to "Herdr Agent Icons Alkaid" so it can sit
beside an installed Max face. Same OFL 1.1 terms (OFL.txt). Built from the Max
face with opentype.js outside this repository; the Max file stays here as its
source.

`HerdrAgentIconsMax-Regular.ttf` is the icon-only face shipped by
[hhdebb/herdr-radar](https://github.com/hhdebb/herdr-radar) (MIT runtime;
glyph design inherited from qintmb/herdr-icon-agent-ui). Vendor marks identify
third-party products and do not imply affiliation.

Muse has no glyph in that face; this plugin falls back to a text mark for it.
